# 线下最小采集规范

这版只为了拿到“可爬取种子 + wrap-up 封面图”，不是为了做完整 CRM。

## 必收

- 一个可用的小红书主页 URL
- 一张封面图
- `source_event`
- `captured_at`

## 可选加分

- `display_name`
- `team_name`
- `team_scope`
- `note`

## collector 规则

- 默认采集者就是 `Zeena`
- 只有明确是别人采集时，才在 JSONL 里显式写 `collector`

## 现场采集步骤

1. 先拿到可用的小红书主页链接。
2. 拍一张后续可以上 wrap-up 页面的一对一封面图。
3. 记录活动来源，例如 `shanghai-demo-day`。
4. 如果你当下知道这个人是谁、他们组在做什么，就补在可选字段里；不知道就留空。
5. 回到电脑后，把一行 JSON 追加到 `xhs_seeds.jsonl`，并把封面图放进 `bd/photos/`。

## 封面图要求

- 每条种子必须正好对应一张封面图
- 封面图会直接进入 wrap-up display
- 只要足够清晰、能代表这个人或这次接触即可
- 这期不要求多图，不要求项目过程照

## 不阻塞的情况

以下信息都不是必填：

- 这个人的真实名字
- 他们组的名字
- 他们组具体在做什么
- 额外备注

只要 URL + 封面图 + 来源场景齐，就可以先入种子库。
